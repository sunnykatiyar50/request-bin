                        Placeholders
                        
    
                            
    {{method}} {{path}} {{ip}}Request method, path after the bin URL, sender IP
    
                            
    {{id}} {{bin}}The captured request's id, the bin id
    
                            
    {{query}} {{query.page}}The whole query string, or one parameter
    
                            
    {{header.user-agent}}A request header (hidden headers stay [redacted])
    
                            
    {{body}} {{body.user.name}} {{body.items[0].id}}The whole body, or a JSON or form field
    
                            
    {{now}} {{timestamp}} {{uuid}}Current ISO time, Unix time in ms, a random UUID
    
                            
    {{query.page | 1}}Text after | is used when the value is missing
    
                        
    
                        
    Values are escaped for the response type (JSON strings, HTML/XML entities). In JSON, numbers and objects are inserted as JSON: {"user": {{body.user}}}.
    
                    
    
                    
    
                        Response rules
                        
    Rules are checked from the top. The first rule whose conditions all match decides the response; any other request gets the response above. Use * as a wildcard in paths and values. A header, query or body condition without a value only needs the field to be present.
    
                        
    
                        
                    
    
                    
    
                        Forwarding
                        
    Forwarding is switched off on this server. Set FORWARD_ALLOWED_HOSTS to the hosts requests may be sent to, then restart.
    
                        
    Pass every request this bin captures on to another URL, as it was sent: same method and body, and the same headers except the hidden ones. The sender's answer isn't affected, and the outcome shows on each request.
    
                        
                        
    
                            
                            
                        
    
                        
    
                        
    With no method ticked, all methods are forwarded.

    API reference
    
                    Examples use this server's address.
                
    
            
    

            
    
                
    
                    
    Capture requests
    
                    
    
                        ANY
                        /b/<bin-id>/<any/path>
                        
                    
    
                    
    Every method, path, query string, header and body is stored exactly as sent, and the bin answers with its configured response. No login or API key is needed, so webhook senders can call it.
    

                    
    Rules
    
                    
    
                        
    SecretBins that require a secret need it in the X-Bin-Secret header, as Authorization: Bearer <secret>, or in a ?secret= query parameter, otherwise 401. Whichever one carried the secret is stored as [redacted].
    
                        
    SizeBodies over MAX_BODY_KB get 413.
    
                        
    HistoryEach bin keeps its newest MAX_REQUESTS_PER_BIN requests; older ones are dropped.
    
                        
    HeadersIn bins with redaction on, Authorization, Cookie, X-API-Key… are stored as [redacted].
    
                    
    

                    
    
                        
    Example
    
                        
                    
    
                    
    
                
    

                
    
                    
    Read captured requests
    
                    
    Send Authorization: Bearer <key> (or X-API-Key) with a Read key from the API keys page, or ADMIN_TOKEN for full access.
    
                    
    
                        
    GET/api/requests/latest?bin=…
    Newest matching request in full (headers, query, body), or 404
    
                        
    GET/api/requests
    bin, method, search, from, to, page, pageSize (max 100)
    
                        
    GET/api/requests/:id
    One request in full; bodyEncoding is utf8 or base64
    
                        
    GET/api/requests/export
    Same filters, plus format (har or json) and ids=1,2,3; newest 1000, oldest first
    
                        
    GET/api/bins
    Bins with their request counts
    
                        
    GET/api/stream?bin=…
    Server-sent events: one request event per new request
    
                        
    ADMINPOST/PATCH/DELETE /api/bins, DELETE /api/requests
    Need ADMIN_TOKEN
